# 空间、身份与跨镜连续性

连续性是让观众理解动作和关系，不要求所有切镜都共享同一构图或同一帧。

## 身份与空间锚点

- 使用脚本和请求提供的稳定人物、场景称呼，避免跨镜换名。按已给设定保持外貌、服装、持物、时间和光线；合理新设计不能冒充已有参考图的内容。
- 对同一场景先明确固定地标、人物之间的位置与朝向、出入口、视线目标和主要运动轴。镜头描述使用画面左/中/右及前/中/后景，不混用人物自身左右和摄影机视角左右。
- 摄影机换位可改变地标的画面位置，要让变化有空间依据。跨轴有叙事意图时通过全景、移动镜头或清楚的重新建立镜头交代，不能让正反打中的双方无原因换边。
- 多人场景追踪未被近景拍到的人仍在何处。人物离开画面不等于离开场景；再次出现应有合理路径，不能忽然消失或传送。
- 追踪决定叙事的道具状态：谁持有、哪只手、是否打开、朝向和损坏程度。镜尾放下的物体，下一镜不能无动作回到手中。

## 首尾交接

- 用上一镜的结束状态核对下一镜的开始状态：姿势、行进方向、目光、持物、对话对象、场景时间与光线是否一致。将有意义的承接写进 video_prompt，避免只写“保持连续”。
- 切到另一场景、跳时、回忆或刻意改变视点时，明确叙事关系与转场，不强行把两个空间融合成一个动作。声音可以跨画面延续，但不能把画外声音误绑为画内角色开口。
- 只有确实需要无缝延续同一状态、且现有 Artifact 已由输入明确指向该状态时，才考虑把上一镜尾帧绑定为下一镜首帧。普通切镜、景别变化和场景切换无需复用同一图片。

## 参考资产绑定

- reference_artifact_ids、start_frame_artifact_id、end_frame_artifact_id 只能选输入允许的真实 ID。参考图用于身份/风格不等于它能用作首帧或尾帧。
- 仅有 ID 而没有图像内容或可靠文字说明时，不能声称已看过图片、识别人脸或验证姿态；不凭 ID 猜哪张属于哪个角色。可以保留用户明确指定的引用，在提示词中说明需要锁定的特征。
- 首尾帧用途不明或尚不存在时留 null，以 image_prompt 和 video_prompt 描述需要的状态；不虚构文件路径、资产、已生成图片或审核结论。
- 场景、角色和道具参考各司其职；不把未提供的全局资产、其他项目资源或上游文档示例带入本项目。

## 局部重规划

selected_shots 存在时只替换所选范围。按 order 将不相邻选择分成独立连续组；每个输出镜头的 source_shot_ids 仅来自一个组，覆盖所有被选组。保留每组必须衔接的入口/出口状态和原作事实，不能跨过未选镜头重排剧情。范围外信息不足时避免编造邻镜内容，优先沿用所选镜头已有的衔接条件。宿主负责插入候选与最终确认。

# 来源与整理方式

整理日期：2026-10-22。规则采用项目原创表述；风格和案例提示词为本项目重新编写，预览图使用对应案例提示词生成。预览用于说明视觉方向，不承诺每次输出相同。

- [OpenAI imagegen](https://github.com/openai/skills/blob/main/skills/.system/imagegen/SKILL.md)、[prompting.md](https://github.com/openai/skills/blob/main/skills/.system/imagegen/references/prompting.md)：参考需求具体程度、按用途组织规格、文字逐字呈现、编辑保留项、参考图职责等原则。
- [YouMind 案例库](https://github.com/YouMind-OpenLab/awesome-gpt-image-2)：研究水彩留白、微缩场景、商业产品和美食的表达维度。[检索 Skill](https://github.com/YouMind-OpenLab/gpt-image-2-prompts-search)用于理解案例推荐与预览的组织方式；网站运行时不依赖该仓库或外部检索。
- [ZeroLu 案例库](https://github.com/ZeroLu/awesome-gpt-image)：研究自然摄影、复古胶片、商品海报、文字排版和角色一致性。具体案例链接随风格返回，页面可查看。

只借鉴构图、光线、媒介、材质和文字层级这些表达方法，不将第三方示例图、品牌、人物身份、长段提示词或商标复制进网站素材。效果图由项目自行生成并随网站发布。

已有 `skills/image-asset-generation` 继续用于复杂资产规划；本 Skill 面向每次日常图片任务，不要求先建立 AssetSpec 或多步规划 packet。

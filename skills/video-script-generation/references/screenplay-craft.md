# 剧情剧本专项方法

本节用于 screenplay：剧情短片、短剧、角色故事和分集剧本。已有原作、世界观、人物关系及用户指定结构是本次创作依据。

## 人物推动因果

- 为主要人物确定当下想要什么、为何现在行动、阻碍是什么、可以用什么办法、失败会失去什么。以这些因素推动选择，避免人物只为作者安排的反转做事。
- 每场围绕一个可感知的变化展开：得到信息、关系改变、计划失败、作出选择或感受加深。场景结束后的状态应能解释下一场为何发生；纯氛围段落也应服务于用户要求的体验。
- 有冲突的题材，用目标差异、信息差、资源限制或代价形成压力。先尝试，再遭遇反馈，必要时调整策略。不能靠所有人突然失去判断力、偶然解围或新出现的设定解决主要问题。
- 铺垫应足以支撑揭示，又不提前讲尽结果。反转可以改变观众的理解，但不能否定已明确展示的事实。三幕、起承转合和悬念收尾仅是可选工具；不强制每场、每集都反转。
- 温柔、日常或无冲突故事可围绕观察、误会消解、共同活动和细微选择推进；保留安静段落的表达空间。

## 可拍摄的分场与对白

- 按所选模板标记场次、内外景、地点、时间及出场人物。环境写足以影响行动的信息；没有要求时不建立冗长设定表或人物小传。
- 动作使用能被看到或听到的描述。把“他终于相信她”落成选择、眼神、停顿或道具动作，不用旁白替代所有心理变化。
- 台词结合人物的目的、关系与信息边界。相同信息在不同人物口中应有不同态度，潜台词通过回避、措辞、动作和回应表现，不只在括号里解释。
- 对话应产生回应或结果，不要求每句都机锋。保留必要的停顿、听者反应和被打断的行动；角色不在场却发声时说明声音来源，不让旁白自动变成现场对白。
- 精确保留用户指定台词、名称与事件。改编原作时区分表现方式调整与情节改写，不能擅自删除关键因果或换掉人物动机。

## 节奏和修订

- 通过人物策略变化、信息揭示与关系转折控制段落轻重。关键选择需要观众看懂，动作也需要起因与结果；不能把“快节奏”变成只剩事件摘要。
- 对照目标时长检查台词可说性、先后动作与情绪停顿。压缩重复解释和重复过场，保留决定性动作及其后果；不输出未经要求的逐镜秒表。
- 有父版本时，以修改理由确定范围，检查局部修改对前后因果的影响并修补必要衔接；保留其他场景、角色关系和有效对白。结尾回应主线；开放结尾要有当前段落的落点。
- 完成后只输出剧本正文。不要附分镜表、模型提示词、制作计划、创作分析或自评。

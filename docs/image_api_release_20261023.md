## 联调期间发现的问题

最初按文档发送 `images[].base64`，生成成功但编辑 HTTP 400（2.625 秒），
供应方明确要求 `images[].image_url`。改成包含 Base64 的 Data URL 后，独立预验收生成和编辑成功。
随后为保留线上刚发布的图片风格库与创作规则，合入现有功能并显式传递比例，再执行上表三轮。
全程共 10 次模型请求：9 次成功、1 次格式不兼容失败；不把最初失败从联调记录中抹去。

# 管理员界面设计参考

研究日期：2026-10-13。范围：本机 Windows 管理端、现有 Python 应用、SSH 发布至 Linux/systemd；仅借鉴交互和操作记录，不引入完整部署平台，不复制第三方代码或商业版功能。

以下实施建议是结合本项目代码作出的设计判断，不能理解为上述平台已经替本项目提供这些保证。

## 建议的信息结构

- **总览**：本机源码标识、当前运行版本、最近测试结果、最近发布状态、执行器/队列基本健康情况；明确本机观察和远端实测的区别。
- **版本发布**：生成并检查发布包 → 查看目标与检查摘要 → 确认部署这个包 → 查看步骤、日志和最终验证。缺少服务器配置时可以完成本地检查与打包，部署按钮显示具体不可用原因。
- **功能测试**：执行固定回归套件；展示通过、失败、跳过、耗时、失败项及受限长度的原始日志。历史报告保存执行时间和源码指纹；源码变化后标记“对应旧版”，不沿用绿色通过状态。
- **操作记录**：按操作 ID 查看操作者、目标、源码/包指纹、开始结束时间、结果；刷新页面不会丢失正在执行的操作。

## 现有部署脚本的实际边界

只读检查了 `scripts/deploy_release.py`、`scripts/apply_release.sh`、现有身份/请求防护和部署说明；没有读取真实服务器配置或凭据，没有连接服务器或运行发布。

已有基础：发布内容限定为程序和运行依赖；拒绝符号链接及明显密钥文件；归档包含逐文件 SHA-256；SSH 严格验证主机，使用非交互认证；远端验证包、脚本摘要与 systemd 配置，使用 `flock` 互斥；独立版本目录完成依赖安装后原子切换 `current`，检查服务 PID 的工作目录和登录配置接口；切换后失败会尝试恢复旧版。

封装成网页按钮时需要补齐以下条件：

1. **管理授权独立检查。** 复用会话中的 `is_admin`，每个管理 API（包括报告下载和日志）均由服务端验证；普通账号与执行器令牌不能调用。沿用 Host/Origin 校验与会话 CSRF，变更只允许 POST；CSRF token 本身不代表管理员身份。部署能力宜限于持有本机源码、测试和 SSH 配置的管理进程，远端运行目录不能冒充本地开发环境。
2. **预检与执行绑定同一包。** 当前 `main()` 每次都会新建 `release_id`、打包和测试，不能用“先 package-only，再重新调用 main”兑现确认发布同一版本。准备阶段应保存包、manifest、脚本快照及检查结果；确认绑定操作 ID、包/脚本摘要、目标配置标识和管理员会话。执行阶段重新校验后只部署该包；目标或内容变化则预检失效。不得允许客户端自选包路径、SSH 目标、配置路径或命令。
3. **报告对应实际源码。** 当前 `fingerprint()` 仅包含运行文件和两个 requirements 清单，不包括测试与部署脚本；新报告还应记录测试/部署脚本指纹、Python/Node 是否可用、检查前后内容是否稳定。JavaScript 语法检查在 Node 缺失时会跳过，不能显示为全部通过。单纯 Git commit 不能反映未提交修改。
4. **只暴露固定动作。** 后台固定解释器、工作目录、脚本、参数白名单，用参数数组启动进程。测试操作运行已知套件，不接收测试模块名、shell 片段、环境变量或任意工作目录。不要在界面内编辑 SSH 私钥、执行任意命令，或放宽 `StrictHostKeyChecking=yes`。
5. **后台执行并持久化状态。** 请求返回操作 ID，轮询或事件流读取结果。测试/打包/部署设置合理互斥、超时和日志上限；重复点击不能生成并行部署。远端已有锁，但本地准备和报告也要防重复与重启丢状态。
6. **区分失败与结果未知。** 当前远程执行异常只有“未返回成功”，不能证明未切换或已回滚。断线、超时、管理进程重启时记录“需核实”，通过受限只读探针检查 `current`、运行 PID、版本和健康状态后再判定；未核实前不得自动再次部署。普通的 GET 刷新不应自行开启 SSH 操作。
7. **不要夸大回退。** `apply_release.sh` 的自动回退只覆盖切换阶段失败；依赖安装失败时尚未切换。回退失败需要明确提示人工处理。恢复旧程序不撤销数据库写入、迁移或服务器配置；无历史版本时不能显示可回退。尚未实现并验证手动回退接口时，只展示现有自动回退说明。
8. **日志按不可信内容展示。** 以纯文本输出，限制大小，屏蔽凭据、令牌、私钥路径与不必要的主机信息；报告下载只允许操作 ID 对应的白名单文件，防止任意文件读取。不要把生产服务完整环境、异常中的配置字典或凭据写入报告。

## 与变更相称的验收

应验证普通用户/匿名/执行器无法访问管理 API；缺少或错误 CSRF 被拒绝；路径和任意命令输入无法改变执行目标；修改已预检内容会阻止部署；同一确认不能启动两次；检查失败、Node 缺失、服务器未配置、SSH 中断、重启遗留操作都有真实状态。用替身验证部署流程，不因管理员界面测试触发真实发布或付费生成。

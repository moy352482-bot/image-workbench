# Qwen 本地模型测试页

入口：`/qwen-test`，管理员登录后可从图片、脚本和 H3 工作台侧栏进入。当前测试版仅管理员使用，不收积分，记录按账号和工作空间隔离，不写入现有图片项目。

支持文生图、单图编辑、双图参考编辑；可选择 FP8 或 Q5_K_M，保留 Qwen-Image-2.1-Turbo 官方 8 步、Euler、CFG=1。文生图可选 1024 或 1536 方图；编辑固定 1024 分辨率档位，画幅由原图确定。双图中第一张是原图，第二张是参考，可在指令中使用 `<image1>` 与 `<image2>`。

随机种子默认留空，新提交会自动选择；实际值显示在任务结果中，手动填写仍原样传给模型，便于对照。点击“用这张图继续编辑”会恢复自动随机。不要沿用生成原图时的种子：Qwen-Image-2.1 在同尺寸、同种子的连续编辑中可能出现噪声重放，表现为近似原图、过度锐化、忽略编辑指令。2026-10-20 用同图同提示词实测，FP8 从种子42改为12345后，金色卷发和蓝眼睛编辑恢复；基础模型也有同样的种子影响。双图人物相似度仍需检查实际输出。[上游排查记录](https://github.com/huggingface/diffusers/issues/14824)。

自动种子与提交标识一起保留；响应丢失后重试不会换种子或重复生成。浏览器回归可运行 `.venv/Scripts/python.exe tests/qwen_seed_browser.py`（可选 Playwright 与本机 Edge，使用模拟 HTTP，不调用模型），覆盖默认随机、手动种子、继续编辑与断线重试。

上传支持静态 PNG、JPEG、WEBP，单张最大 20 MiB、1600 万像素。服务器校验、按 EXIF 方向转正并规范化为 PNG，再供执行器下载；本机再次验证哈希，上传到只监听本机的 ComfyUI。生成结果由执行器读取、校验并回传云端，网页提供前后对照、PNG 下载和继续编辑。

## 本机启动

双击项目根目录 `启动Qwen网页测试.cmd`，它会先启动 `D:/ComfyUI/Qwen21` 的 ComfyUI，再在后台启动网站测试执行器。重复启动会复用同一执行器。没有设置开机自启动；电脑重启后需重新运行。网站仍可接收排队任务，需电脑开机联网后才能出图。

配置是 `deploy/qwen-worker.local.json`，示例见同目录 `qwen-worker.example.json`。沿用受保护的 `C:/Users/win/AppData/Local/ImageWorkbench/Tencent/remote-worker.json` 读取服务器地址和执行器令牌。令牌不放入命令行、源码或网页。

只读检查：

```powershell
.\scripts\start_qwen_worker.ps1 -Check
```

日志与后台进程记录保存在 `C:/Users/win/AppData/Local/ImageWorkbench/Tencent/qwen-worker-process.json` 及它指向的日志文件。缓存位于 `.remote-cache/qwen-remote/`，包含原图、提交检查点和结果；应保留以便断线后继续回传。

## 执行与恢复

网站使用独立持久队列，一次处理一张图，每账号最多三个活动任务，全局最多六个。同一个提交标识重复上传只返回原任务；修改图片、指令或参数后才形成新的提交。用户可取消尚未领取的任务，刷新和下载不会再次调用模型。

执行器在提交模型前落盘记录意图，收到回执后保存 prompt ID。提交响应丢失时只查询同一工作流，无法唯一确认则显示“状态待确认”，不会盲目重发。结果回传和完成确认可以重复进行，服务端通过 SHA-256 拒绝覆盖不同结果。请勿删除未完成任务的本机缓存；模型重启丢失历史时需要人工核对原任务。

执行器与已部署 H3 执行器共用 GPU 文件锁，检查 ComfyUI 队列后才生成。开始前释放空闲 H3 实例的模型缓存，结束后释放 Qwen 实例的模型缓存，给其他本机任务留出显存。直接在 ComfyUI 界面提交的任务不经过网站的 GPU 锁，请避免手动同时运行两个模型实例。

服务器数据位于数据根目录 `.qwen-lab/`。完整备份需包含该目录；备份期间停止 Qwen 执行器并避免提交测试，确保队列、原图和输出一致。代码回退不会删除测试数据。

## 验证范围

新增自动化检查覆盖管理员访问、CSRF 与源站约束、空间隔离、坏图和越界参数、提交幂等、排队取消、执行器心跳、输入/输出哈希、断线恢复、不重复生成及双图工作流绑定。真实联调包括 FP8 单图编辑、Q5 文生图、FP8 双图参考编辑；网页上传、状态轮询、前后对照及刷新后恢复均已检查。

模型文字能力沿用本机实测结论：每轮只改一处相对更可靠；复杂泰文可能漏字、保留错误或改动商品细节。测试页用于观察和比较实际效果。

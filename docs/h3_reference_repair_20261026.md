# H3 参考图上传与回收站状态修复

## 原因与范围

2026-10-26 线上排查确认：受影响的 H3 项目仍被列在工作台中，但其关联主项目已经软删除。
H3 项目列表和详情仅检查自身记录中的账号、Workspace，没有检查关联主项目的回收站状态。
因此页面能打开，初始化创作流程和读取关联参考图却返回 404；文件选择和拖拽上传都在初始化阶段失败。
受影响的五张原图文件仍存在，SHA-256 与原 Artifact 记录一致。

修复归属为 Video Application Service 与 Frontend，继续复用 `IdentityStore.ownership` 和
原有项目恢复接口。列表、详情和后续写入统一检查关联主项目可用性；未关联图片项目的历史 H3
项目保持兼容。恢复原主项目后，原 H3 项目及参考图直接恢复可见，无需复制图片或创建新 ID。

若当前页面打开期间项目被删除或移出 Workspace，刷新会清除失效项目与素材选择，说明回收站恢复
或开始新作品的路径，同时保留尚未提交的图片、脚本和镜头文字草稿。
过期异步响应不能清空已经切换到的新项目。

没有新增数据模型或修改 Core；不改变积分、生成参数、任务提交、Worker 恢复和归档。
代码不会自动撤销用户的删除操作。具体项目恢复需按用户选择，调用现有恢复服务。
回滚代码不需要数据迁移；原图片和项目记录保留。

- Chromium：当前项目删除后保留草稿，通过文件选择和拖拽开始新作品，两张图片均可显示且不扣积分。
- 既有图片粘贴、文件选择、拖拽、去重、跨项目异步响应与 H3 回归继续由统一检查覆盖。

# 看图与基底对比

点击任务结果图片可打开大图。点击缩放按钮或按 `Z` 放大/缩小，放大后可拖动查看细节；按 `Esc` 关闭，焦点返回原图片按钮。查看器保留下载原图与打开原图入口。单边超过 3000 像素的图片使用原预览，并提示下载原图查看细节。

有基底图片的编辑任务，在每张结果下方显示“与基底对比”。尺寸一致时左右拖动分隔线；键盘聚焦后，`←` / `→` 每次调整 5%，`Home` / `End` 显示其中一张。尺寸不同、记录与实际尺寸不符或组件不可用时并排展示，保持图片比例。透明部分使用同一棋盘背景。

打开、缩放和对比都是查看操作，不创建任务、不改变审核状态、不扣积分。图片仍通过原有账号与 Workspace 接口访问；组件与样式由工作台本机托管，没有第三方图片服务或 CDN 请求。

图片加载失败时会显示恢复提示；关闭后刷新任务并确认登录状态，再重新打开。组件下载暂时失败会回退；之后重新打开可重试。查看器支持触摸手势，本轮已验证桌面鼠标、键盘和窄屏布局，尚未在实体触摸设备上验收双指操作。

使用固定版本 PhotoSwipe 5.4.4 与 img-comparison-slider 8.0.7。后者有两处本地生命周期修复，用于关闭时释放 ResizeObserver；保留原文件、补丁说明和来源摘要。许可证及来源见 [第三方组件说明](third_party_components.md)，本轮证据见 [R11 验收记录](../work/iterations/R11/review.md)。

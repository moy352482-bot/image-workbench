# 素材交互与脚本生成

图片工作台支持选择文件、粘贴剪贴板图片、多图拖拽和选择当前项目图片。
上传内容按真实图片格式校验，同一子项目内相同字节复用已有 Artifact。
文本粘贴保持浏览器原有行为，上传失败可重试。

视频工作台的素材暂存区可折叠，保存当前项目的图片和已完成视频引用。
图片可继续修改、作为参考图、首尾帧，或传入选定分镜；视频可绑定为镜头成品。
移出暂存区只移除引用，原文件仍可下载。视频文件通过同卷硬链接登记，
不支持硬链接的存储会明确报错。项目和 Workspace 权限仍逐次检查。

两个脚本入口自动显示所选模型与思考强度的积分，点击“开始生成”即可提交。
服务端提交时重新计价并校验模型可用性和余额；手动选择不会被悄悄替换。
模板、风格、TXT 导出、历史版本和独立分镜选项保留。
重复提交仍按请求 ID 去重，失败释放冻结积分。

免费模型同样创建任务与执行记录，默认每账号 60 秒最多 6 次提交、最多 3 个在途任务，
可通过既有正整数环境配置调整。独立分镜真实模型未定价时不能当作免费调用。

完整验证覆盖 35 项浏览器用例；真实 Windows/macOS 剪贴板来源、
浏览器差异和付费生产模型质量仍应按实际设备单独验收。

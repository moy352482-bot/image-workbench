## 本轮已采取的控制

- 修改前保存源码与文档快照；基线完整验证 639 项，4 项环境跳过。
- Ruff 记录 134 条历史问题，CI/统一入口拦截新增；没有批量自动修复。注册表装配改动顺带消除了两条旧 lambda 赋值告警。
- 新增脚本插件门面和启动禁用配置，未移动数据库、产物、版本或 Worker；停用仍允许历史和已受理工作恢复。
- 架构负例检查覆盖 Core→HTTP、脚本→视频、插件→Storage/HTTP；不扩大任意导入白名单。
- 修订开发入口，要求新功能先说明归属、依赖、复用、模型、Core 影响、波及面、验证与回滚。

## 明确推迟的工作

不做通用插件市场/动态发现/热卸载，不一次拆分所有大文件，不统一迁移所有 Version，不替换 JSON/SQLite，
不引入 Prefect/Temporal，不把 Skill 中的候选接口标记为已实现，不改现有价格或生成确认策略。

历史 Ruff 问题按触及范围处理：优先检查 B023 闭包绑定是否有真实异步行为风险，再处理未使用导入与纯格式。
`F401` 中存在兼容重导出，删除前必须核对公开导入合同；不能为了消除告警破坏旧入口。
若阶段目标变成多主机调度、长时间人工等待或恢复人工处理成为主要运维成本，再据实评估工作流框架。

# 实现决策

1. 保持 StorageManager 结构与已有物理文件。新增上传经现有图片验证/登记方法保存到子项目素材任务；逻辑引用保存 Artifact ID，不重复复制模块间素材。
2. 视频旧资产记录兼容保留；新资产记录链接已有 Artifact。现有视频上传接口、Workspace 校验与 Worker 契约保留。
3. 原生 paste event 统一处理 Ctrl+V/Cmd+V，仅在识别到图片时接管；文本或未知剪贴板内容交给浏览器。一个页面仅安装一个输入协调器。
4. 所有异步上传捕获原项目/空间上下文，响应不得写入已切换的编辑页面；添加引用，不静默覆盖已有素材。
5. 脚本价格单一来源仍为 `config/script_pricing.json`，该文件已符合用户价目，无需修改。前端展示为估计，提交时后端重新计算、校验并冻结积分。
6. 使用现有 unittest、FastAPI TestClient 和已安装 Playwright。隔离测试数据，模型使用 Mock/本地 fixture。
7. 原目录多聊天并发编辑，使用独立本地副本，最终合并以三方差异与回归测试为依据。
8. 视频片段使用真实 MP4 Artifact；既有视频通过同卷硬链接登记规范产物路径，不额外复制视频字节。移出暂存区只改逻辑元数据。
9. 脚本免费保护按账号跨 Workspace 计数，默认 60 秒 6 次、最多 3 个在途任务；幂等返回先于限流。最终检查与冻结积分在同一数据库事务中。
10. Windows 浏览器读取与归档竞争导致的短暂文件占用使用有界原子替换重试；不重放模型调用，不隐藏持续写入错误。
11. 隐藏素材库任务不能用通用移动接口改变归属；上传复用固定任务前再次校验归属及素材库标记。已有错位记录明确拒绝继续写入。
12. 脚本生成成功返回任务后立即显示任务快照，即使首次详情读取失败也持续查询恢复；重试查询不重复提交。
